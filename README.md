# AutoNoder

AI-powered workflow automation platform inspired by the Nodebase architecture from the supplied two-part course documentation.

## Project status

Initial repository setup. The application architecture and implementation will be built from the supplied Part 1 and Part 2 specifications.

## Planned architecture

- Next.js + TypeScript
- React Flow workflow editor
- Prisma + PostgreSQL/Neon
- Better Auth
- Inngest workflow execution and realtime events
- AI integrations: OpenAI, Anthropic, Gemini
- Workflow triggers and integrations
- Encrypted credential management
- Execution history and error tracking
- Payments/subscriptions with Polar
- Sentry observability
- Production deployment
